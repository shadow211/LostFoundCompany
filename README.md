# 寻物小铺 · Hidden Object（Godot 4 复刻练习 · v8）

一款隐藏物品（Hidden Object）寻物小游戏，按 Steam 上《Lost and Found Co.》
（《失物招领有限公司》）这类找物游戏的**玩法结构与画法**复刻：
扁平卡通描边风的大场景里塞满物品，帮客人按清单把丢失的东西找回来。

> 关于素材：原作画面是其画师手绘的商业美术资产，无法也不应直接搬用。
> 本作四幅场景图是**原创生成的插画**——画法对齐原作（细暖棕线、
> 扁平色块、赛璐璐 shading、无墙大地图景观），但构图、地点、物品
> 均为独立创作；代码、对话、角色名也均为原创。

## 玩法

- **BGM 与音效**：全程有轻松的八音盒风循环 BGM（代码合成、原创旋律）；
  点击、找到物品、点空、提示、通关都有对应音效
- **点中目标：亮绿圈 + 橙色气泡**：参考原作视频，点中瞬间物体立刻被
  一个荧光绿粗圆圈圈住（带绿色星点），正上方冒出橙色圆角气泡写
  “找到了！”，0.9 秒后留绿圈✓标记，清单打勾；点中目标只轻轻弹一下，
  不再大放大
- **场景里每个人/动物/花草都是活的**：每关 8–9 个“住户”——街上散步
  的小人、市集里逛摊的人、花园和公园里的小鸟、睡觉的猫、花丛、竹林、
  石灯、路灯，身份都按画面里实际的东西核对过。它们平时就待机呼吸
  （起伏/轻摆），每隔几秒自己动一下（小鸟叫、小人蹦、猫打哈欠、花摇、
  灯亮），点中做本色动作、不计分、不收集；天上还一直飘着花瓣/叶子
  （小镇粉、集市黄、花园粉、公园橙）。住户和彩蛋一样不在清单里——
  向日葵转了半天也不算找到，就是因为它本来就不是要找的物品。
  **第 1 关的人物/动植物已是独立透明精灵**：从场景原图里抠出来
  （描边墙漫水 + 羽化椭圆兜底，`tools/extract_street.py`），底板是
  抠掉人物后补上背景的版本，所以待机呼吸、点中动作都只有人物本身在动，
  背景一动不动；静止时精灵和底板严丝合缝。第 2–4 关目前还是方形补丁，
  待按同一套办法批量替换（清单见 `RESOURCE_INVENTORY.md`）
- **悬停也有动画，但不缩放**：鼠标移到任何可交互物体上（未找到的目标
  、彩蛋或住户），只提亮 + 持续脉动的金圈 + 手形光标，目标还会在右侧清单里
  把对应行标成橙色；猫不会因为鼠标移上去就变大，角色动作只在点中时
  才做。移开即复原（住户的补丁常驻显示，只复原提亮），拖动平移时不触发，
  悬停不收集、不计失误，已找到的目标不再悬停；点空地才计失误

- **委托对话开场**：每关先由客人说明委托，点完对话才开始计时；
  通关后有结尾对话
- **手绘大场景**：场景图 1600×1067，比屏幕大——**拖动平移、滚轮缩放**
  （以光标为中心），有「重置视图」；提示时相机会自动移到目标附近
- **物品就藏在画里**：点中目标物品留下绿圈✓标记并收集；点空计失误；
  右侧清单带物品小图标，找到后打勾
- 4 关，目标递增：小镇街道 6 个 → 热闹市集 8 个 → 阳光花园 10 个
  → 秋日公园 10 个；四关全部是无墙大地图（街道/市集/花园/公园），
  花田、小径、摊位、池塘成片，场景里有小动物和路人
- 找齐按用时/失误/提示评 1–3 星，最佳成绩保存（`user://progress.json`）

## 运行

1. 安装 [Godot 4.5](https://godotengine.org/download)（免费）
2. 解压本包，用 Godot 导入 `project.godot` 所在目录
3. 按 F5 运行；也可以在编辑器里「项目 → 导出」生成可执行文件

## 与原作仍不同的地方（如实说明）

- 原作有角色在场景中走动交谈、物件可开合互动、连续剧情章节
  与房间装饰系统；本作的场景是平面插画：第 1 关的人/动物/花草已是
  独立透明精灵，会待机呼吸、每隔几秒自己动一下、点中有本色反应，
  天上还飘着花瓣/叶子，但没有角色走动、物件开合与连续剧情；
  第 2–4 关的人物还是方形补丁（动起来会带背景），待批量替换
- 场景图为生成的原创插画，画法已对齐（扁平卡通描边），
  但具体图形是独立创作，不是原作的原画
