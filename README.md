# 寻物小铺 · Hidden Object（Godot 4 复刻练习 · v5）

一款隐藏物品（Hidden Object）寻物小游戏，按 Steam 上《Lost and Found Co.》
（《失物招领有限公司》）这类找物游戏的**玩法结构与画法**复刻：
扁平卡通描边风的大场景里塞满物品，帮客人按清单把丢失的东西找回来。

> 关于素材：原作画面是其画师手绘的商业美术资产，无法也不应直接搬用。
> 本作四幅场景图是**原创生成的插画**——画法对齐原作（细暖棕线、
> 扁平色块、赛璐璐 shading、无墙大地图景观），但构图、地点、物品
> 均为独立创作；代码、对话、角色名也均为原创。

## 玩法

- **BGM 与音效**：全程有轻松的八音盒风循环 BGM（代码合成、原创旋律）；
  点击、找到物品、点空、提示、通关都有对应音效
- **点中目标：画笔画圈**：像拿笔画圈一样，0.55 秒一笔把物品圈出来，
  画完留绿圈✓标记，飘一句“找到了！”，清单打勾；点中目标只轻轻弹一下，
  不再大放大
- **彩蛋各有本色动作，不计分**：彩蛋不在清单里，点中只做它自己的事，
  不画圈、不提示“找到了！”、不计失误也不收集——向日葵转了半天也不算
  找到，就是因为它本来就不是要找的物品。猫/狐狸打哈欠（慢慢伸长再缩回，
  飘“哈～/喵～/呼～”），小鸟叫（连跳两下，飘“啾啾♪”），向日葵/花摇动
  （左右摆，不转圈），灯笼/石灯亮一下，浇水壶倾斜倒水（飘“哗啦”），
  布料堆被风吹抖两下，兔子跳起。每关 4–5 个彩蛋，身份都按画面里实际
  的东西核对过（市集右下角原来点在空草丛上的一个，已移到蓝花上）
- **悬停也有动画，但不缩放**：鼠标移到任何可交互物体上（未找到的目标
  或彩蛋），只提亮 + 持续脉动的金圈 + 手形光标，目标还会在右侧清单里
  把对应行标成橙色；猫不会因为鼠标移上去就变大，角色动作只在点中时
  才做。移开即复原隐藏，拖动平移时不触发，悬停不收集、不计失误，
  已找到的目标不再悬停；点空地才计失误

- **委托对话开场**：每关先由客人说明委托，点完对话才开始计时；
  通关后有结尾对话
- **手绘大场景**：场景图 1600×1067，比屏幕大——**拖动平移、滚轮缩放**
  （以光标为中心），有「重置视图」；提示时相机会自动移到目标附近
- **物品就藏在画里**：点中目标物品留下绿圈✓标记并收集；点空计失误；
  右侧清单带物品小图标，找到后打勾
- 4 关，目标递增：小镇街道 6 个 → 热闹市集 8 个 → 阳光花园 10 个
  → 秋日公园 10 个；四关全部是无墙大地图（街道/市集/花园/公园），
  花田、小径、摊位、池塘成片，场景里有小动物和路人
- 找齐按用时/失误/提示评 1–3 星，最佳成绩保存（`user://progress.json`）

## 运行

1. 安装 [Godot 4.3+](https://godotengine.org/download)（免费）
2. 解压本包，用 Godot 导入 `project.godot` 所在目录
3. 按 F5 运行；也可以在编辑器里「项目 → 导出」生成可执行文件

## 工程结构

```
project.godot          工程配置（主场景、自动加载、窗口 1280x800）
assets/scene_*.webp    四幅原创扁平卡通描边风场景图（1920×1280）
audio/*.wav            BGM 与 6 个音效（Python 代码合成，原创旋律）
scenes/Main.tscn       主菜单（关卡选择 + 最佳星级）
scenes/Game.tscn       关卡场景
scripts/state.gd       全局状态与存档 + 音频系统（BGM 循环/音效池）
scripts/levels.gd      4 关数据：场景图、目标热点、彩蛋物体、对话
scripts/game.gd        核心玩法：图片场景、相机平移缩放、对话、热点判定、提示、评星
scripts/main.gd        菜单 UI（代码构建）
scripts/item_draw.gd   20 种物品的矢量绘制（用于清单小图标）
scripts/item_icon.gd   清单小图标
scripts/found_marker.gd 找到物品后的绿圈✓标记
scripts/sparkle.gd     找到物品的星光特效
scripts/hint_ring.gd   提示光圈特效
scripts/hover_ring.gd  悬停时持续脉动的金圈
scripts/draw_circle.gd 找到物品时画笔画圈（0.55 秒一笔画完）
scripts/float_text.gd  飘字（猫“哈～”、鸟“啾啾♪”、找到“找到了！”）
fonts/                 内置 Noto Sans CJK 字体，保证中文显示
tests/smoke_test.gd    无头冒烟测试（36 项断言）
tests/screenshot.gd    截图脚本（含热点圈对齐验证图）
```

## 与原作仍不同的地方（如实说明）

- 原作有角色在场景中走动交谈、物件可开合互动、连续剧情章节
  与房间装饰系统；本作是平面插画场景 + 热点点击，没有角色
  走动与开合动画
- 场景图为生成的原创插画，画法已对齐（扁平卡通描边），
  但具体图形是独立创作，不是原作的原画
